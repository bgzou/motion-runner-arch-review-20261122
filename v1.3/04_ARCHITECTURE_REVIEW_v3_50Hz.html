四进程，一个出口

进程 ≠ 模块 ≠ 线程03 / 19
讲者备注：四个 MC 进程加 HAL。Gateway 是前台/调度；Worker 是后厨，可以慢但不能阻塞出菜口；RT 是出菜口/最后质检，200 Hz 必须准时；Safety 是安全员，只能否决不能抢写；HAL 是司机，能独立拒收。只要记住“一个出口”。

时钟

三个时钟，不是一次同步调用

Worker 20 ms 出候选；RT 5 ms 自己跑；HAL 约 1 ms 执行

50/200/1k 是建议目标，不是实测04 / 19
讲者备注：三个周期独立：Worker 20 ms 出一次候选，RT 每 5 ms 自己跑，HAL 1 ms 级执行。50 Hz 策略下一个目标保持 4 个 RT tick，这是 ZOH，不是插值。RT 不会等到 15 ms 才动；它只读当前仍有效的候选，过期就丢。

时序 · 安全

急停不经过 ONNX

硬件链先动；Safety 撤许可；RT 不再采纳普通候选；HAL 独立保护

软件保护 ≠ 硬件保护11 / 19
讲者备注：急停最先动的是电气/硬件，不是软件。Safety 只是撤许可、锁存；RT 不再采纳普通候选；HAL 和驱动还有独立 watchdog。不要把这套软件层讲成“已经满足功能安全”，硬件链没验证就不能上机。

权限

四把钥匙，不能合成一个 boolean

谁在请求 → 谁拥有运动资源 → 现在允许动吗 → 谁有权写设备

四把钥匙 = 四个检查点12 / 19
讲者备注：用钥匙类比：Session 是工牌，ControlLease 是方向盘钥匙，SafetyLease 是安全员放行条，HAL writer 是设备钥匙。四个不是一个 boolean；任何一个失效，正常运动都不能继续。SafetyLease 过期时，有方向盘也不能动。

HAL

HAL 不是“把数字发给电机”

它翻译单位/方向，验 writer/seq/epoch/CRC/deadline，并在设备侧独立保护

HAL 是设备合同，不是 Runner13 / 19
讲者备注：HAL 在中间：左边 MC 给规范目标，右边设备域执行。它做三件事：翻译单位/方向、验 writer/seq/epoch/CRC/deadline、独立拒收/保护。它不做推理、不选 Action、不读 Manifest。软件合同通过不代表硬件 watchdog 真的有效，需要 HIL。

安全

从 INIT 开始，不从 HOLD 开始

未知支撑时不得把“保持当前位置”当成安全动作

状态机有迁移边，不是 5 个卡片14 / 19
讲者备注：这里重点讲 INIT：上电不知道姿态/支撑，不能默认 SAFE_HOLD，也不能默认 NORMAL。INIT 先禁用正常输出；支撑/姿态/反馈可信才允许 SAFE_HOLD。ESTOP 只能物理复位+维护授权+自检后回 INIT，不能自动恢复。Q2B/Balance 在 UNKNOWN 下全部禁用。

风险

哪些不能讲成“已解决”

评审时主动说出来，比被问出来好

P0 · can_exit 竞态

Worker 在 step 前发布 READY；随后 step 挂死/NaN/进入不可中断 phase，RT 仍可能用旧 READY 提交。必须补“READY→挂死/NaN/phase 变更→0 次提交”的测试。

P1 · ModePlan / Factory / HAL 能力未机器化

ModeTransitionPlan、Q2B/B2Q phase、工厂矩阵、HAL 能力表仍有文档/测试硬编码；编码前要补 schema/validator。

P1 · ExitKind 值差异

V1.1 C++ 片段与 proto 的枚举值不一致；编码以 proto 为准，不要手写第二套枚举。

P1 · Schema 语义缺口

UNKNOWN 下 SAFE_HOLD、BUILTIN 带 path、空 tensor/predicates、asset hash 覆盖不足；需要 mcctl 跨字段负例。

不能上机

Collie 拓扑/标定、双足支撑、Q2B/B2Q 资产、HAL 独立 watchdog、WCET、功能安全、密钥管理都未签收。

可以做什么

可以拆接口/骨架/配置/回放/测试任务；P0 先关闭。不要把“可编码”说成“可上机”。

主动暴露风险，评审才有效18 / 19
讲者备注：这页建议主动讲，不要等别人问。P0 是 can_exit 竞态；P1 是 ModePlan/Factory/HAL 能力未机器化、ExitKind 值、Schema 语义。能编码不代表能上机。把“现在不能做什么”讲清楚，评审才会信任“能做什么”。

Q&A

五个最可能被问的问题

一句话答，细节回到 Part/附录

1. 五个责任区怎么对应四个进程？

责任区管语义/所有权，进程管故障隔离，线程管周期；不要求数量一一对应。

2. 为什么只有 RT 能写 HAL？

一个关节必须在一个有截止、所有权和保护判据的出口做最终决定；其他模块只给候选/许可。

3. Worker 20 ms、RT 5 ms 怎么不等待？

两边独立 tick；RT 只读当前仍有效的封存候选，没有就降级/保护，不同步等 Worker。

4. ControlLease 与 SafetyLease 区别？

前者是“谁拥有运动资源”，后者是“此刻允不允许动”；发放者、过期响应不同。

5. 36/36 通过为什么不能上机？

它们是 SIL/合同/Schema/文本检查，未验证真实驱动、watchdog、急停、动态支撑。

6. 现在最该做什么？

先修 P0 can_exit 竞态，再补 ModePlan/Factory/HAL capability schema，最后才开真实动作边。
